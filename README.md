# EWU Faculty Course Assignment & Scheduling System

## Project Description

The EWU Faculty Course Assignment & Scheduling System is a database-backed web application developed for the CSE302 Database Systems course.
The system is designed to manage faculty members, courses, sections, and class schedules in an East West University context.

## Key Features

- User login and authentication
- Admin and User roles
- Faculty management
- Course management
- Section management
- Class schedule management
- Create, Read, Update and Delete (CRUD) operations
- MySQL database integration

## User Roles

### Admin
- Add, view, update and delete faculty
- Add, view, update and delete courses
- Add, view, update and delete sections
- Add, view, update and delete class schedules

### User
- View faculty information
- View courses
- View sections
- View class schedules

## Technologies Used

- HTML
